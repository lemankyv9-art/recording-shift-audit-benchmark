# Recording-shift audit benchmark

Data, stored predictions, protocols and scripts for the article *Auditing the reuse of accident-investigation data under distribution and recording shifts: a mechanism-informed simulation study* (under review).

The repository supports two uses:

1. **Fixed-data reanalysis of the simulation benchmark.** Every record is generated by an explicit event, casualty, loss and recording mechanism: 30 paired replicates in stationary, composition-shift and injury-mechanism-shift scenarios. New domain-adaptation or recording-robust methods can be fitted to the same replicates and compared with the stored metrics without regenerating data.
2. **Illustrative audits of public crash databases.** Scripts, derived tables and run logs for the STATS19, Department for Transport fatal-collision contributory-factor, CRSS, NMVCCS and FARS–CRSS audits reported in Section 6 of the article.

Read `PROVENANCE.md` and `SCOPE.md` for interpretation limits. Monte Carlo intervals describe uncertainty under the specified data-generating process, not sampling uncertainty for real accidents.

## Contents

| Path | Contents |
|---|---|
| `data/` | Fixed replicate matrices and scenario files (`data/datasets/rXX/<scenario>/`), codebook and data manifest |
| `results/` | Stored predictions, per-replicate metrics, summaries, verification reports and extension outputs |
| `replication/` | Analysis, verification, secondary-analysis, audit-extension and figure-building scripts, with the frozen protocols |
| `manuscript/figures/` | Vector figures used in the article and supplement |
| `pilot/` | Observed-database audit scripts, derived tables and logs (see `pilot/README.md`) |
| `MODEL_SPECIFICATION.md`, `PROTOCOL_NOTES.md` | Mechanism and protocol notes |
| `external_evidence.json` | Ledger of the public reports used only as qualitative mechanism references |
| `MANIFEST.json` | SHA-256 checksum of every file in the repository |

The scenario keys `stationary`, `covariate_shift` and `conditional_shift` are the stationary, composition-shift and injury-mechanism-shift scenarios of the article.

## Reproduce the fixed results

The analyses used Python 3.13 with the package versions pinned in `replication/requirements.txt`. From the repository root:

```sh
python -m pip install -r replication/requirements.txt
python replication/verify_integrity.py
python replication/verify_secondary.py
python replication/verify_reporting.py
python replication/build_publication_figures.py
```

The verification scripts check dataset invariants, stored probabilities, metric recomputation, paired-scenario identities, decision costs and the seed-level factorial Monte Carlo intervals. `verify_reporting.py` also cross-checks reported values against the manuscript sources when they are placed in `manuscript/`; the manuscript is not included while it is under review, so those text checks are skipped. The figure builder reads fixed result files only. `replication/README.md` describes the remaining scripts.

## Not included

- **Record-generation and extension-fitting code.** These scripts are kept in a separate construction workspace, so the repository supports fixed-data reanalysis and extension-summary verification but not end-to-end regeneration of every reported experiment. They can be supplied for methodological review.
- **Most raw third-party crash data.** The audits use public files from the UK Department for Transport and the US National Highway Traffic Safety Administration. Apart from two small UK files described in `pilot/README.md`, they are not redistributed; that file lists the sources and where each script expects its inputs.
