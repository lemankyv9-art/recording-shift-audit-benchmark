# Scope

This release contains a stylised simulation study, not an accident-report transcription or a population-calibrated sample. Records have generated keys and no real dates or event identities. Primary conclusions refer to the fixed mechanism and protocol only. The independently generated test cohort is not an independently collected real-world cohort.

The article and supplement use the current data, predictions and summaries. Earlier materials are archived outside this directory. Data-generation scripts remain in the separate construction workspace.
