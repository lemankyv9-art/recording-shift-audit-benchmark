# Fixed v3.2 simulation-study data

All rows are generated by the specified event, casualty, loss and recording process. `source.csv`, `target.csv` and `external_test.csv` are convenience copies of `datasets/r00/covariate_shift/`; the full tree contains 30 fixed replicates and three scenarios.

Source has 343 rows; target has 121 rows (36 development, 85 holdout); the independent cohort has 2,000 rows per scenario. `model_factors.csv`, `recorded_features.csv` and `assessment_mask.csv` separate latent factors from recorded flags for diagnostics. Only the 20 recorded H/V/E flags enter primary models. See Section 2 of the article's supplementary material for the numerical specification.
